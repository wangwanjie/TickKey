# TickKey 1.1.2

## 新功能

- 系统可直接用 TickKey 打开 `.tickkey` 加密备份：Mac 上在访达中双击或拖到 Dock 图标，iPhone 上在「文件」中轻点，或在邮件、聊天、隔空投送中选择「用 TickKey 打开」，即进入导入流程。
- 开启解锁保护时，先完成身份验证再导入；导入前自动退出多选并收起设置页。
- iPhone 从其他应用接收的备份副本在读取后立即删除，不留在应用沙盒中；「文件」中的原文件保持不变。

## 分发

Mac 版按架构分别提供：Apple 芯片下载 `TickKey-1.1.2-arm64.dmg`，Intel 下载 `TickKey-1.1.2-x86_64.dmg`，已安装的版本可通过自动更新升级。

明文备份和二维码包含账户密钥，请仅交给可信设备。Ad Hoc IPA 仅能安装到已加入描述文件的设备。
