# TickKey 1.1.0

## 新功能

- 解锁保护：开启后，启动、回到前台或锁屏后需要通过面容 ID、触控 ID 或设备密码解锁才能查看验证码；默认关闭，开关前需验证身份。Mac 可用 ⌘L 立即锁定，系统睡眠或锁屏时自动上锁。
- 从剪贴板导入：支持复制的 otpauth 链接、Google Authenticator 迁移链接和二维码截图（iPhone 与 Mac）。
- Mac 支持导入二维码图片、一次选择多个文件，以及把备份文件或二维码图片直接拖到窗口导入。
- Mac 补全标准菜单：关于、隐藏、关闭窗口（⌘W）、查找（⌘F）、主窗口（⌘0）、从剪贴板导入（⇧⌘V）。
- 导出文件名带日期，多次备份不再互相覆盖。

## 修复与改进

- 修复 Mac 账户较多时窗口打开后停在列表底部、看不到前几个账户的问题。
- 修复 iPhone 保存账户后系统弹出「保存密码」、可能把 TOTP 密钥存入 iCloud 钥匙串的问题。
- Mac 复制的验证码标记为敏感临时内容，剪贴板管理工具不会记录。
- otpauth 导出同时写入「发行方:账户」标签，并严格编码 `+`、`&` 等字符，提高与其他验证器的兼容性；导入时兼容冒号后带空格的标签。
- Google Authenticator 迁移链接兼容 URL 安全或无填充的 Base64。
- 导入进行中再编辑账户时提示「正在导入」，不再误报保险库错误。
- 单元测试宿主改用临时保险库，测试不再接触真实账户和钥匙串。

## 分发

Mac 版按架构分别提供：Apple 芯片下载 `TickKey-1.1.0-arm64.dmg`，Intel 下载 `TickKey-1.1.0-x86_64.dmg`。已安装 1.0.2 的用户通过自动更新会获得与本机架构一致的版本。

明文备份和二维码包含账户密钥，请仅交给可信设备。
