# TickKey 1.0.1

- 修复浏览器 Authenticator 插件的文本备份在账户名称为空时整批导入失败的问题。
- 支持只填写发行方的 TOTP 条目，保留原始空账户名称，避免补造名称影响精确去重。
- 文本导出和二维码保留 `发行方:` 标签；加密备份、编辑和本地存储同步支持此类账户。
- 发行方与账户名称均为空、密钥无效或参数错误时，仍拒绝整个导入。
- 按项目 SwiftFormat / SwiftLint 规范整理代码，补充职责注释、方法内分段和严格构建检查。
- 最低 iOS 版本更新到 15.0。

13 项 macOS 核心回归测试通过。另使用用户提供的 50 条记录在本机内存中验证了解析、验证码生成和两种备份往返；真实账户和密钥未加入仓库或测试资源。
